# 🌐 คู่มือระบบจำลอง Spatial Metaverse เพื่อการศึกษานิทรรศการเสมือนจริง 3 มิติ
### (Spatial-Like Educational Metaverse Platform & Virtual Expo Guide)

---

## 🎯 1. วัตถุประสงค์และภาพรวมโครงการ
ระบบจำลอง **Spatial Metaverse เพื่อการศึกษา** พัฒนาขึ้นเพื่อเป็นแพลตฟอร์มการเรียนรู้และจัดนิทรรศการดิจิทัลสามมิติ (3D Virtual Exhibition) โดยถอดแบบลูกเล่นและประสบการณ์การใช้งานมาจาก **Spatial.io (Spatial Metaverse)** ที่ได้รับความนิยมทั่วโลก เพื่อให้ครูผู้สอนสามารถนำไปจัดกิจกรรมการเรียนรู้ นำเสนอนวัตกรรมของนักเรียน และฝึกฝนทักษะดิจิทัลแห่งศตวรรษที่ 21

---

## 🌟 2. สรุปฟังก์ชันหลักที่ถอดแบบจาก Spatial Metaverse

| คุณสมบัติของ Spatial | ฟังก์ชันที่พัฒนาขึ้นในโปรแกรม | ประโยชน์ในการเรียนการสอน |
| :--- | :--- | :--- |
| **1. พื้นที่สาธารณะสำหรับจัดนิทรรศการดิจิทัล** | ห้องโถงแกลเลอรี 3D สไตล์ Modern Minimalist มีกรอบรูปภาพ, แท่นจัดแสดงประติมากรรม และระบบแสงเงาสมจริง | นักเรียนเรียนรู้การจัดวาง Space, แสง และการนำเสนอผลงานศิลปะ/โครงงาน |
| **2. สร้างตัวตนเสมือน (Avatar) ด้วยกล้อง** | ระบบ **Webcam Face Mapping** ถ่ายภาพใบหน้าผ่านกล้องหน้า แล้วนำมาตัดแปะเป็น Texture บนหน้าอวตาร 3D ทันที พร้อมเลือกสีชุดเสื้อผ้า | ให้นักเรียนรู้สึกมีตัวตนเสมือน (Presence) ที่เชื่อมโยงกับตัวเองจริงๆ เหมือนใน Spatial |
| **3. แชร์หน้าจอในพื้นที่เมตาเวิร์ส** | **WebRTC Screen Sharing** ดึงภาพหน้าจอ สไลด์ PowerPoint หรือ YouTube ฉายสดขึ้นจอภาพยนตร์ยักษ์ 16:9 ในหอประชุม | ครูใช้สอนสด หรือนักเรียนใช้พรีเซนต์งานกลุ่มต่อหน้าเพื่อนๆ ได้ทันที |
| **4. กระดาษบันทึกข้อความ (Sticky Notes)** | แผ่น Post-it 3 มิติ หลากสี (เหลือง, ชมพู, เขียว, ฟ้า, ส้ม) สามารถพิมพ์ข้อคิดเห็น แล้วกดแปะลงบนกำแพงห้องนิทรรศการได้ | ส่งเสริมการประเมินโดยเพื่อน (Peer Review) และการสะท้อนคิด (Reflection) |
| **5. อัปโหลดและปฏิสัมพันธ์กับเนื้อหาหลากหลาย** | รองรับโปสเตอร์ 2D, โมเดล 3D หมุนได้ (ดาวเทียม, DNA, กังหันลม, ควอนตัม AI), ระบบ **Audio Guide** อ่านออกเสียงภาษาไทยอัตโนมัติ (TTS) | รองรับพหุปัญญา และผู้เรียนที่ถนัดการรับรู้ผ่านภาพ เสียง และมิติสัมพันธ์ |
| **6. รองรับผู้เข้าชมได้สูงสุด 100 คน** | ระบบ **Crowd Simulator** จำลองเพื่อนร่วมชั้น 10 - 100 คน เดินชมนิทรรศการ นั่งฟังบรรยาย และส่งเสียงปรบมือ + ระบบซิงค์ข้ามแท็บ (BroadcastChannel) | สร้างบรรยากาศห้องเรียนที่มีชีวิตชีวาแม้เปิดทดสอบบนเครื่องเดียว |
| **7. การเชื่อมต่อ Identity สากล** | หน้าล็อกอินสไตล์ Spatial รองรับ Google Workspace, Microsoft 365, MetaMask (Web3 Wallet) และ Quick Student Join | ปลูกฝังความเข้าใจเรื่อง Digital Identity และเทคโนโลยี Web3 |
| **8. การมีปฏิสัมพันธ์และกิจกรรมเสมือนจริง** | ระบบ Reaction Emojis (👏 ปรบมือ, ❤️ ส่งใจ, 🔥 เยี่ยม, 🙋 ยกมือถาม) มีเสียงสังเคราะห์และละอองอนุภาคลอยขึ้นฟ้า | สนับสนุน Gamification และการมีส่วนร่วมในชั้นเรียนออนไลน์ |
| **9. สลับมุมมองบุคคลที่ 1 และ 3** | กดปุ่ม `[V]` เพื่อสลับระหว่าง First-Person (เดินชมเสมือนจริง) และ Third-Person (มองเห็นอวตารตนเอง) | ให้นักเรียนเลือกมุมมองการนำทางที่สะดวกที่สุดตามความถนัด |
| **10. ส่งออกและนำเข้าข้อมูล (.json)** | บันทึกห้องนิทรรศการทั้งห้องเป็นไฟล์ JSON ส่งให้ครูตรวจ หรือโหลดผลงานเพื่อนมาจัดแสดง | สะดวกต่อการเก็บสะสมผลงาน (Digital Portfolio) และการประเมินผล |

## 🚀 3. วิธีการเปิดใช้งานโปรแกรม

### วิธีที่ 1: ดับเบิลคลิกไฟล์คำสั่ง (ง่ายที่สุดสำหรับเครื่อง Mac)
1. เข้าไปที่โฟลเดอร์โครงการ `/Users/iladapinpat/Downloads/นวัตกรรม`
2. ดับเบิลคลิกที่ไฟล์ **`เปิด_Spatial_Metaverse.command`**
3. ระบบจะเปิด Local Web Server และเปิดเบราว์เซอร์ Google Chrome หรือ Safari ให้อัตโนมัติ พร้อมใช้งานกล้องและแชร์หน้าจอได้ทันที 100%

### วิธีที่ 2: เปิดด้วย Live Server หรือ Localhost
1. รันคำสั่ง `python3 -m http.server 8080` ภายในโฟลเดอร์โครงการ
2. เปิดเบราว์เซอร์ไปที่ `http://localhost:8080/spatial-metaverse/`

## 🎮 4. การควบคุมตัวละครในโลกเสมือน

| ปุ่มกด (Keyboard / Mouse) | หน้าที่การทำงาน |
| :--- | :--- |
| **W / A / S / D** หรือ **ปุ่มลูกศร** | เดินหน้า / ถอยหลัง / เลี้ยวซ้าย / เลี้ยวขวา |
| **Spacebar** | กระโดด (Jump) ข้ามสิ่งกีดขวาง |
| **คลิกเมาส์ค้างแล้วลาก** | หมุนมุมกล้องมองรอบทิศทาง 360 องศา |
| **ปุ่ม [E] หรือคลิกที่ชิ้นงาน** | เปิดดูรายละเอียดผลงานนิทรรศการ / ฟังคำบรรยายเสียง Audio Guide |
| **ปุ่ม [V]** | สลับมุมมองบุคคลที่ 1 (First-Person) และบุคคลที่ 3 (Third-Person) |
| **ทัชสกรีน (iPad / มือถือ)** | ใช้ Virtual Joystick ด้านซ้ายล่างเพื่อเดิน และรูดหน้าจอด้านขวาเพื่อหมุนกล้อง |

## 📚 5. แนวทางการจัดกิจกรรมการเรียนรู้ (Lesson Plan ตัวอย่าง 3 คาบ)

### คาบที่ 1: ก้าวสู่โลกจักรวาลนฤมิต & สร้างตัวตนดิจิทัล (Introduction to Metaverse & Avatar Identity)
- **ขั้นนำ (10 นาที):** คุณครูฉายหน้าจอแนะนำแนวคิด Metaverse และแพลตฟอร์ม Spatial
- **ขั้นกิจกรรม (30 นาที):** ให้นักเรียนล็อกอินเข้าสู่ระบบ ทดลองเปิดกล้องเว็บแคมเพื่อสแกนใบหน้าของตนเองลงบน Avatar และเลือกชุดเสื้อผ้าที่ชอบ
- **ขั้นสรุป (10 นาที):** นักเรียนทดลองเดินสำรวจห้องนิทรรศการ และฝึกส่ง Reaction ปรบมือและแชททักทายกัน

### คาบที่ 2: ออกแบบและจัดบูธนิทรรศการกลุ่ม (Curating Digital Exhibition)
- **ขั้นนำ (10 นาที):** ครูอธิบายขั้นตอนการจัดนิทรรศการและการวางแนวคิด (Concept / Storytelling)
- **ขั้นกิจกรรม (30 นาที):** 
  - นักเรียนแต่ละกลุ่มเลือกกรอบรูปภาพที่ว่างอยู่ กด `[E]` เพื่อเปิดระบบ **Curator Studio**
  - ใส่ชื่อโครงงาน, ผู้วิจัย, ข้อความแนวคิด, และใส่สคริปต์คำบรรยายเสียง (Audio Guide)
  - **แนบไฟล์สไลด์นำเสนอ (PPT / PPTX / PDF)** หรือวางลิงก์ Canva/Google Slides เพื่อให้ผู้เข้าชมและครูกดเปิดดูสไลด์เต็มตาได้
  - ทดลองชมโมเดล 3D บนแท่นประติมากรรม
- **ขั้นสรุป (10 นาที):** กลุ่มนักเรียนกดบันทึกผลงาน และทดสอบระบบอ่านออกเสียงอัตโนมัติพร้อมทดสอบเปิดสไลด์นำเสนอ

### คาบที่ 3: มหกรรมนิทรรศการเปิดบ้าน & Peer Review (Virtual Expo Day)
- **ขั้นนำ (5 นาที):** ครูใช้เครื่องมือ Teacher Broadcast ประกาศเริ่มงาน และเรียกรวมตัวนักเรียนที่หน้าหอประชุม
- **ขั้นนำเสนอ (25 นาที):** 
  - ตัวแทนกลุ่มใช้ฟังก์ชัน **"🖥️ แชร์หน้าจอ"** ฉายสไลด์นำเสนอนวัตกรรมขึ้นจอภาพยนตร์ยักษ์
  - นักเรียนคนอื่นนั่งฟังบนอัฒจันทร์ และส่งปฏิกิริยา ปรบมือ 👏 / ส่งหัวใจ ❤️
- **ขั้นแลกเปลี่ยนและประเมินผล (20 นาที):**
  - นักเรียนเดินชมผลงานกลุ่มเพื่อน และใช้ฟังก์ชัน **"📝 แปะโน้ต (Sticky Notes)"** เขียนคำชมและข้อเสนอแนะแปะไว้ข้างผลงาน
  - ทำแบบประเมิน Rubric 5 ดาวให้คะแนนความคิดสร้างสรรค์และประโยชน์ของโครงงาน
  - ครูดาวน์โหลดไฟล์สรุปนิทรรศการ (.JSON) เพื่อเก็บเป็นคลังผลงานโรงเรียน
